CPI Inflation Analysis
📌 Project Overview

This project analyzes Consumer Price Index (CPI) data to understand inflation trends across different sectors and categories over time.

The analysis uses monthly CPI data covering Rural, Urban, and Rural+Urban sectors and examines changes across major categories such as food, health, housing, transport, education, clothing, and other household expenses.

The project was developed using Microsoft Excel with a focus on data preparation, exploratory data analysis (EDA), trend analysis, and extracting meaningful insights from inflation data.

🎯 Project Objectives

The project focuses on:

Understanding overall CPI inflation trends over time.
Exploring inflation across different sectors — Rural, Urban, and Rural+Urban.
Analyzing inflation trends across major categories and sub-categories.
Comparing changes in food, health, housing, transport and other important CPI components.
Studying year-over-year (Y-o-Y) inflation patterns.
Examining inflation trends before and after the COVID-19 period.
Identifying categories that contributed to changes in overall inflation.

📁 Workbook Structure

The Excel workbook is organized into multiple sheets:

1. Raw Data

Contains the original CPI dataset used as the starting point for the analysis.

2. Main Data

Contains the prepared dataset used for analysis, including additional calculated fields.

3. Data Dictionary

Provides information about the variables and their meaning.

4. Notes

Contains supporting notes and information related to the analysis.

5. Objective 1 — EDA & Analysis

Exploratory analysis performed for the first project objective.

6. Objective 2 — EDA & Analysis

Analysis focused on the second project objective.

7. Objective 3 — EDA & Analysis

Further exploratory and comparative analysis of CPI data.

8. Objective 4 — EDA & Analysis

Includes analysis of pre-COVID and post-COVID Y-o-Y inflation, including comparisons across major categories such as health, food, housing, and transport.

🔍 Key Areas of Analysis

The project explores:

Overall inflation movement over time.
Differences between Rural and Urban inflation.
Changes in food-related inflation.
Movement of housing and fuel-related prices.
Inflation in health and transport categories.
Year-over-year changes across CPI components.
Pre-COVID versus post-COVID inflation patterns.
📈 Project Outcome

The analysis provides a structured view of how consumer prices changed over time and how inflation varied across sectors and expenditure categories.

It demonstrates the use of Excel for real-world data analysis, including data preparation, exploratory analysis, calculations, comparisons, and interpretation of trends.
